# 每日盘前必读 · 执行流程（DAILY_README）

本文件是"盘前必读"自动化任务的完整执行规范。每次自动化会话启动后，请先阅读本文件，然后严格按章节执行。所有数据采集、报告生成、GitHub 同步均按本文档执行，静默完成，无需用户确认。

---

## 一、执行总览

1. 数据采集：加载 `mx-ds-mcp` 技能，通过妙想 MCP 获取行情、新闻、公告数据
2. 报告生成：加载 `html-report` 技能，按"金融终端风"主题生成报告
3. 归档：复制报告到仓库 `archive/YYYY-MM-DD/`，修正共享库引用深度
4. 同步：浅克隆（若仓库不存在）+ 纯推送（`--force-with-lease`），不同步远端历史下来
5. 更新 `history.html`：Python 全量重写，列出全部归档

> 注意：当前会话中本仓库已通过浅克隆存在于 `/workspace/daily-market-read/`，通常无需重新克隆，直接使用即可。若目录不存在，按第四节"Git 同步"中浅克隆步骤执行。

## 三、报告生成（html-report + 金融终端风）

加载 `html-report` 技能，输出目录 `/workspace/盘前必读_YYYYMMDD/`（含 `index.html`、`assets/charts.js`、`_shared/`）。

### 主题样式（金融终端风）

- 背景：深海军蓝 `#0d1b2a`（主背景）/ `#1b263b`（卡片）/ `#243447`（区块头部）
- 标题点缀：金色 `#d4af37`；正文 `#e0e1dd` / 辅助 `#778da9`；边框 `#2a3a52`
- 涨：红色 `#e63946`；跌：绿色 `#2a9d8f`；警示 `#f4a261`
- 顶栏：深色渐变 + 红色底边框，标题居中，下方显示日期和"交易日早报"标签
- 区块标题：深色区块头部 + 金色编号 + 白色标题；数据卡片：深色背景、大字号加粗、涨跌着色
- 表格：深色表头、行悬停高亮、涨跌幅红绿着色；必要时使用 ECharts 图表
- 整体：专业金融终端质感，深色底 + 金色点缀 + 红绿涨跌色

### 报告结构

1. **市场温度计**：3-5 句行情总结导读 + 热门板块数据卡片/表格 + 当日市场热点预判
2. **隔夜回顾与外盘速递**：美股/港股/亚太行情卡片 + 全球指数对比 ECharts 图
3. **宏观要闻**：货币政策、经济数据发布、政策发布、地缘政治等新闻列表
4. **板块前瞻**：机器人/商业航天/半导体等热点新闻 + 强势个股表格
5. **个股公告速览**：业绩预告、增减持、重大合同、重组等公告表格
6. **操作建议概览**：大盘预判 + 今日关注方向 + 风险提示

### 报告底部

- 内容末尾、footer 之前，新增"盘前必读 · 历史归档"跳转按钮，相对路径 `<a href="history.html">`，样式：深色底 + 金色边框 + 金色文字，悬停金色底白字
- footer 注明：数据来源为东方财富及公开网络信息，仅供参考，不构成投资建议
- 日期使用报告生成当天的实际日期；内容遵循涨红跌绿规则

## 四、归档与更新首页

报告生成后立即执行：

```bash
REPO=/workspace/daily-market-read
SRC=/workspace/盘前必读_YYYYMMDD
DATE=YYYY-MM-DD

# 1. 归档：复制整目录后删除 _shared，并重写归档 HTML 的共享库引用深度
mkdir -p $REPO/archive/$DATE
cp -r $SRC/* $REPO/archive/$DATE/
rm -rf $REPO/archive/$DATE/_shared/
# 目录归档的 HTML 引用 ../../_shared/（上两级到仓库根共享库）
find $REPO/archive/$DATE -name "*.html" -type f | while read f; do
  sed -i 's|\./_shared/|../../_shared/|g' "$f"
done

# 2. 更新首页（文件级覆盖，禁止 cp -r 到已存在目录，否则会嵌套成 assets/assets/）
cp $REPO/archive/$DATE/index.html $REPO/index.html
cp $REPO/archive/$DATE/assets/charts.js $REPO/assets/charts.js
# 同步最新字体到根目录共享库
cp $SRC/_shared/fonts/*.ttf $REPO/_shared/fonts/
```

## 五、Git 同步（浅克隆 + 纯推送）

### 读取凭据

GitHub token 从自动化任务的会话环境中读取（由任务消息注入的 `GH_TOKEN` 环境变量），禁止硬编码到命令或文档。

```bash
GH_OWNER="UP-Mingyi"
GH_REPO="daily-market-read"
GH_BRANCH="main"
GH_TOKEN="$GH_TOKEN"   # 由自动化任务注入
```

### 浅克隆（仅当仓库不存在）

```bash
if [ ! -d /workspace/daily-market-read/.git ]; then
  git clone --depth 1 "https://${GH_TOKEN}@github.com/${GH_OWNER}/${GH_REPO}.git" /workspace/daily-market-read
fi
cd /workspace/daily-market-read
```

### 纯推送（不同步远端下来）

```bash
git config user.name "$GH_OWNER"
git config user.email "$GH_OWNER@users.noreply.github.com"
git add .
git commit -m "feat: $DATE 盘前必读报告归档"
git push --force-with-lease origin "$GH_BRANCH"
```

- 浅克隆仓库必须用 force 类推送（普通 push 会报 "shallow update not allowed"）
- `--force-with-lease` 比 `--force` 安全：若远端被意外改动会失败而非覆盖
- 兜底：若 push 被拒（远端有本地没有的提交），临时 `git pull --rebase origin "$GH_BRANCH"` 后重推一次

## 六、更新 history.html

用 Python 全量重写模板，兼容目录归档与独立文件归档，按日期倒序：

import os, re
REPO = "/workspace/daily-market-read"
ARCHIVE = os.path.join(REPO, "archive")
entries = []
# 目录归档 archive/YYYY-MM-DD/（优先 index.html，兜底目录内任意 .html）
for name in sorted(os.listdir(ARCHIVE)):
    d = os.path.join(ARCHIVE, name)
    if os.path.isdir(d) and re.fullmatch(r"\d{4}-\d{2}-\d{2}", name):
        idx = os.path.join(d, "index.html")
        if os.path.isfile(idx):
            entries.append((name, f"archive/{name}/index.html"))

## 八、关键注意事项

1. **禁止 `cp -r` 覆盖已存在的 `assets/` 目录**：目标目录存在时会嵌套复制成 `assets/assets/`，必须用文件级 `cp` 覆盖 `assets/charts.js`。
2. **归档 HTML 的共享库引用深度**：目录归档（`archive/YYYY-MM-DD/`）用 `../../_shared/`；独立文件归档（`archive/YYYY-MM-DD.html`）用 `../_shared/`。删除归档内 `_shared/` 后，报告依赖根目录共享库仍可正常渲染 ECharts。
3. **路径替换只做一次**：从原始报告复制后 `./_shared/` → `../../_shared/` 一次到位。切勿对已替换过的文件再次执行 `./_shared/` 替换，否则会因 `../_shared/` 内含 `./_shared/` 子串产生 `.../../_shared/` 污染。若需修复历史污染，用正则 `[./]*_shared/` 整体归一化。
4. **history.html 需兼容两种归档格式**：目录（含 `index.html` 或目录内任意 `.html` 兜底）与独立 `.html` 文件，按日期倒序排列，用 Python 全量重写模板最稳健。
5. **根目录共享库保持最新**：`_shared/js/echarts.min.js` 与 `_shared/fonts/` 需与最新报告一致，否则字体回退、图表依赖缺失。
6. **浅克隆必须 force 推送**：普通 push 在浅克隆仓库会报 "shallow update not allowed"，必须用 `--force-with-lease`。
7. **凭据不硬编码**：GitHub token 从自动化任务注入的环境变量读取，妙想 API Key 从 `/data/user/mcp/mcp-servers.json` 读取，禁止写入命令或文档。
8. **报告实际输出路径**：html-report 技能生成的是目录 `/workspace/盘前必读_YYYYMMDD/`（含 `index.html`），归档时复制整个目录内容。
